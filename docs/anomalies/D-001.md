# D-001 — Anomaly Brief

> **Note:** This anomaly was seeded deliberately for the SheetShift software demonstration.

| Field | Content |
|---|---|
| **Anomaly ID** | D-001 / Lint A1 |
| **Cells** | `Calc!O2:O41` (entire `ded_factor` column) |
| **Workbook formula** | `=VLOOKUP(Policies!H2,RateTables!$A$31:$B$35,2,TRUE)` |
| **Column rule** | Same as workbook formula |
| **Manual rule** | R-205, p. 5 (see verbatim quote below) |
| **Rows affected** | 11 of 40 sample rows (Policies!H: rows 3, 4, 13, 15, 19, 22, 24, 27, 29, 34, 38 all have deductible ≥ $10,000) |
| **Premium impact** | Sample rows: not computable until decision patch applied (service and workbook both use the short range today, so the harness sees 0 delta for these rows). What-if on 10,000 generated policies (computed outside Bob, by Claude Code, using DedBands): 1,874 policies have deductible ≥ $10,000; total_due falls for 1,842 of them (min −$7.22, median −$322.95, max −$2,010.60). |
| **Options allowed** | `keep-workbook` · `adopt-manual` · `escalate` |
| **Recommendation** | `adopt-manual` (see reasoning below) |
| **Confidence** | High |

---

## Governing rule — verbatim

**R-205 Deductible factors** (p. 5):

> "The AOP deductible factor is taken from the band that contains the policy's AOP deductible. The factor applies to the AOP premium only (R-100, step 2)."

**Table 205** (p. 5):

| AOP deductible from | To | Factor |
|---|---|---|
| $0 | less than $500 | 1.10 |
| $500 | less than $1,000 | 1.00 |
| $1,000 | less than $2,500 | 0.92 |
| $2,500 | less than $5,000 | 0.82 |
| $5,000 | less than $10,000 | 0.74 |
| **$10,000** | **and over** | **0.66** |

---

## Discrepancy

The workbook VLOOKUP range is `RateTables!$A$31:$B$35` (5 rows). The named range `DedBands` covers `RateTables!A31:B36` (6 rows). The sixth row — with key 10,000 and factor 0.66 — is present in the table block and in the named range, but is excluded from the VLOOKUP range.

**Effect:** A policy with AOP deductible ≥ $10,000 falls off the bottom of the lookup table. Under approximate VLOOKUP (TRUE), this returns factor 0.74 (the $5,000 band) instead of the manual's 0.66. Any such policy is overcharged for the deductible credit.

**Sample scope:** Reading `Policies!H2:H41` directly from the workbook via `office_read`, 11 of the 40 sample policies carry a deductible of $10,000 or more (rows 3, 4, 13, 15, 19, 22, 24, 27, 29, 34, 38). These 11 rows currently show no harness delta because the service translates the same short range as the workbook; the mismatch would become visible only after a decision patch extends the range to `DedBands`.

---

## Analysis of options

### `keep-workbook`
The workbook range is one row shorter than both the named range `DedBands` and Table 205. This produces a wrong factor for deductibles ≥ $10,000 and conflicts with the filed manual. There is no manual authority to support this deviation.

### `adopt-manual`
Use `DedBands` (= `RateTables!$A$31:$B$36`) as the lookup range. This matches Table 205 exactly and is consistent with the named range already defined in the workbook. This is the correct filed behaviour.

### `escalate`
Appropriate if the underwriting or compliance team has further context — for example, if the $10,000 deductible option is not offered in the market and the missing row is intentional.

---

## Recommendation

**`adopt-manual`** — The six-band table in the filed manual is unambiguous. The omission of the $10,000 row appears to be an editing error in the workbook (the named range `DedBands` already includes it). 11 of the 40 sample policies carry a deductible of $10,000 or more, confirming that the affected band is in active use in the sample. The what-if on 10,000 generated policies (computed outside Bob, by Claude Code) shows 1,842 affected rows with a median total_due reduction of $322.95 and a maximum of $2,010.60 — a material overcharge against the filed rate. Adopting the manual removes the overcharge and aligns the service with R-205.

**Confidence: High** — The manual is unambiguous, 11 of 40 sample policies are demonstrably in the affected band, and the what-if quantifies the production impact as both widespread and financially material.
