## 4. Integration fixes made in this pass

1. **`harness/common.py` `service_steps`** accepts Bob's documented STEPS shape: `fn` as the function name and `file` as a repo-relative path. It resolves the name to the loaded function by name and file and adds `name_fn` for the trace. `C.rel` now accepts repo-relative paths. A self-check test covers this.
2. **`harness/trace.py` gate** also fails on a column tagged twice and on an out-of-scope cell that is not in the graph, as `.bob/rules/10-cell-traceability.md` promises. The certificate reason lists these too.
3. **`harness/EXPECTED_TREE_SHA256`** was rewritten to `83791152…f3e7` for changes 1 and 2. **A person must review the harness diff** before the first commit.
4. **Makefile.** `certify` no longer depends on `trace`, whose exit 1 used to stop the certificate being written. Added a `manual` target. `check` now runs `tools/tests` and `check_modes`.
5. **`tools/dump_workbook.py`** can be run as `python3 tools/dump_workbook.py`, the wording used in the rules and the guard tests.
6. **Hooks.**
   - `smoke_summary` prefers the harness's own `line` and reads the `error` field.
   - `guard`'s fail-closed pattern covers `reports/*.json|jsonl|html`, `build/`, `manual/`, `audit/` and `CONTRACT.md`.
7. **Site.**
   - The index page fetches `baseline.json` only when `site.json` lists it, which removes a 404.
   - The replay task table no longer stays at "Loading…" when there are no events; this was a real bug.
   - The footer reads "Commit not recorded yet".
8. **Other.**
   - `requirements-dev.txt` adds `pypdf` (BSD), used for the manual text check.
   - `docs/CONTRACT.md` §4 and §5 record the STEPS, XLError and units conventions, the 170 + 2 fixed golden rows, the decision ids and the `escalated` class.
