## 4. Integration fixes made in this pass

1. **`harness/common.py` `service_steps`** accepts Bob's documented STEPS shape: `fn` as the function name and `file` as a repo-relative path. 2. **`harness/trace.py` gate** also fails on a column tagged twice and on an out-of-scope cell that is not in the graph, as `.bob/rules/10-cell-traceability.md` promises. The certificate reason lists these too.

4. **Makefile.** `certify` no longer depends on `trace`, whose exit 1 used to stop the certificate being written. Added a `manual` target. `check` now runs `tools/tests` and `check_modes`.
5. **`tools/dump_workbook.py`** can be run as `python3 tools/dump_workbook.py`, the wording used in the rules and the guard tests.
6. **Hooks.**
   - `smoke_summary` prefers the harness's own `line` and reads the `error` field.
   - `guard`'s fail-closed pattern covers `reports/*.json|jsonl|html`, `build/`, `manual/`, `audit/` and `CONTRACT.md`.
7. **Site.**
   - The index page fetches `baseline.json` only when `site.json` lists it, which removes a 404.

## 4b. Review fixes (second pass, same day)

A review of the scaffold produced 15 confirmed and 20 minor findings; the fixes are below. Each
harness change is covered by a self-check test, and **`harness/EXPECTED_TREE_SHA256` was rewritten
to `fee7c895…e730` (`python3 harness/_hash_tree.py --write`). A person must review the harness diff
before committing.**

1. **CI.**
   - A root `.gitleaks.toml` (default rules plus a path allowlist for the guard-test fixtures) makes the full-history secret scan pass.
   - The name and file-name checks are now one hashed "Denylist scan" (`tools/denylist_scan.py`, `.github/denylist.sha256`), so the CI file no longer spells the words.
   - The oracle step uses `git status --porcelain`, so an uncommitted patched oracle fails, and it checks the patched `decisions_sha256`.
   - A missing certificate (pending service) sets PENDING instead of crashing.
   - A hygiene step rejects committed reports from a non-default service.
   - `check_evidence.py --final` runs on manual runs and `submission*` tags.
   - `.gitleaks.toml` and `.gitattributes` are protected paths.
2. **Line endings.** `.gitattributes` forces LF for text (`* text=auto eol=lf`), so Windows checkouts hash correctly.
3. **Mutation self-test.**
   - An unmutated control copy runs through the same worker first; if it fails, the report is `invalid` and certify is RED.
   - Mutants and naive operators are compared against the original **and** the patched oracle (a cell counts if it changed against either).
   - Certify warns when more than half of the mutants die by crash.
4. **Other harness fixes.**
   - A partial service (`ImportError: cannot import name`) is reported as pending.
   - LibreOffice runs under the C locale, and a comma-decimal number in the oracle CSV fails the build.
   - Decimal service values get numeric deltas, so rounding groups are classed correctly.
   - The decision queue carries `runtime.total_due_delta` for the anomaly briefs.
5. **Guard and hooks.**
   - The hooks have no tool matcher; the guard skips a list of read-only tools (`READ_ONLY` in `_common.py`, to be confirmed in T00) and checks everything else.
   - Windows commands are checked: backslash paths, PowerShell and cmd write verbs, and `-Path`/`-Destination`.
   - It also catches `bash -c`, inline-Python writes (`shutil`, `os.*`, `write_text`), `find -delete`, `xargs` writers, `pushd`, `git -C`, `python -m tools.decide`, case-insensitive paths and XML `<path>` arguments.
   - Read-only commands (`cat decisions/…`, `grep 'open('`) are no longer blocked.
   - A logging failure no longer changes the decision.
   - The payload sample is keyed by `event:tool`.
   - Non-guard hooks end with `|| exit 0`.
6. **Bob pack and prompts.**
   - Smoke results are read from `reports/smoke_last.json` (the hook result is not injected until the next prompt).
   - The `tables.py` API is pinned in CONTRACT §4, T02 and the unit briefs, and T03 is just `/shift-translate all`.
   - The adjudication brief takes the premium impact from the queue or says "not computed".
   - The pre-flight activates the venv.
   - Portable scrub `sed`, plus a case-insensitive home-path check in `check_evidence.py`.
   - T00 has diff-edit and shell probes and step 8 writes the probe note; the T00 expectation now matches the log.
   - T02 has the iferror exception, T07 the `OUT_OF_SCOPE.json` cell key, and T11 is marked not ready (the map, plan and sheetshift commands are HO-3 only).
   - Translator and triage modes can write `docs/notes/HARNESS-<n>.md`.
7. **Site and docs.**
   - The banner states only what it can check.
   - `site.json` carries `exports_available`.
   - The footer lists everything Claude Code generated.
   - README claims are qualified until T00/T01, the certificate links are marked "after the final run", and a deploy note was added.
   - `uvicorn` is now a dev dependency.
   - The embedded document dates are explained in PROVENANCE.md.
   - Comment references now point to public documents (README, CONTRACT, bob_prompts).
